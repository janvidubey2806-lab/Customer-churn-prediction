Customer Churn Prediction

Project Overview

Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave a service or continue using it.

The project uses customer data to identify churn patterns and estimate customer churn probability.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib

Machine Learning Model

- Logistic Regression
- Train-Test Split
- Model Evaluation
- Prediction Probability

Key Features

- Customer data analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Customer churn prediction
- Churn probability display
- Customer risk assessment
- Interactive Streamlit web application

Dataset

IBM Telco Customer Churn Dataset.

How to Run the Project

1. Clone or download this repository.

2. Install the required libraries:
   
   "pip install -r requirements.txt"

3. Run the Streamlit application:
   
   "streamlit run app.py"

Project Goal

To understand customer behavior and use Machine Learning to identify customers who may be at risk of leaving a service.
